## Requirement schema

Each requirement includes: **ID**, **priority** (`P0`/`P1`/`P2`), **rationale**, **acceptance test**, **dependencies**, **source**.

Priority: `P0` blocks prototype/release; `P1` required before funnel release; `P2` scheduled improvement.
