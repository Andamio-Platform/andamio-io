# GitHub and AI Resources

Catalog repositories, libraries, models, agents, evaluation tools, and implementation references using the [normalized methodology](../methodology.md).

Keep records grouped by use case, not popularity. State the exact Andamio need, license, source availability, pricing model, maintenance evidence, claim-level citations, freshness metadata, verified date, and score. AI entries must also document data handling, provider dependence, evaluation evidence, and whether deterministic fallback behavior is required.

Lifecycle: `proposed → researching → verified → shortlisted → adopted`; evaluation may end at `rejected`, adopted entries may become `superseded`, and stale or changed evidence returns an entry to `researching`. Promote only fresh, verified candidates to the [shortlists](../shortlists/README.md).
