# UI/UX Resources

Catalog primary research, standards, design references, interaction patterns, accessibility guidance, and tested examples using the [normalized methodology](../methodology.md).

Organize evidence around issuer comprehension and conversion first, then developer discovery. For each record, identify the user problem, applicable viewport or interaction, accessibility implications, claim-level citations, freshness metadata, evidence strength, verified date, and constraints imposed by the canonical design system.

Lifecycle: `proposed → researching → verified → shortlisted → adopted`; evaluation may end at `rejected`, adopted entries may become `superseded`, and stale or changed evidence returns an entry to `researching`. Visual similarity alone is not evidence. Promote only fresh, verified, outcome-linked resources to the [shortlists](../shortlists/README.md).
