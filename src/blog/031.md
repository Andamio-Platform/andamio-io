#### *We've just released version 1.4.0 with some exciting new features and important changes. Here's what you need to know:*
---

## **⚠️ Important: Wallet Support Change**
We now support [Eternl](https://eternl.io/) and [Lace](https://www.lace.io/) wallets only. If you're using a different wallet, please switch to *Eternl* or *Lace* to continue using the platform. We've made this change to improve connection reliability and security.

---

## **🎉 What's New**
### Course & Project Publishing is Live!
You can now activate your courses and projects directly from the platform:
- Course activation: 150 ADA
- Course + Project bundle: 250 ADA

### **Smart bundling**
If your project requires a course that hasn't been published yet, the platform will detect this and offer to publish them together in one transaction.

### Better Task Management
- Clearer commitment workflows: We've fixed bugs and improved how task commitments work throughout their lifecycle
- Improved project owner reviews: Better interface for reviewing task submissions, with clear options to refuse (before deadline) or deny (after deadline)
- Enhanced contributor dashboard: Easier to see your tasks, their status, and what actions you need to take

### Smoother Experience
- Better evidence submission: Fixed the double-click save issue and improved the review workflow
- Clearer transaction costs: When you make transactions, you'll see detailed breakdowns of all fees
- Visual improvements: Better distinction between different commitment statuses so you always know where things stand

---
## **🐛 Bug Fixes**
We fixed several issues that were affecting your experience:
- Expired task commitments now handle properly with correct status transitions
- Assignment evidence saves correctly on first click
- Project owners can now add project managers as intended
- Wallet connection issues resolved
- New user dashboard redirects working correctly

---

## **📋 What This Means for You**
## If you're a learner:
- Expect clearer feedback when completing assignments
- Transaction costs are now more transparent

## If you're a course creator:
- You can now publish courses and projects yourself
- The platform helps you publish prerequisites automatically

## If you're a project contributor:
- Task commitment process is more reliable
- You'll see clearer status updates on your dashboard

## If you're a project owner:
- Better tools for reviewing task submissions
- Can now properly add project managers to your projects
